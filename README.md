# AP Computer Science Principles Create Task

This project is an interactive basketball trivia game where users can test their knowledge of NBA players and their statistics.

The game uses NBA player statistics to create trivia questions and provides an interactive way for users to explore basketball knowledge.

## Features

- Basketball trivia questions
- NBA player statistics
- Interactive user experience

## Languages Used

- JavaScript
- HTML
- CSS

## Development

Originally created on Code.org for the AP Computer Science Principles Create Task. Additional modifications were made to adapt the project for GitHub Pages.
